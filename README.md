<h1 align="center">Sistema de Gerenciamento de Oficina</h1>

## 📋 Descrição

**OrderTech** é uma aplicação desktop desenvolvida em **Java** com a biblioteca gráfica **Swing**, voltada para o gerenciamento de serviços de uma oficina mecânica. 

O sistema permite realizar o **cadastro e gerenciamento de clientes, veículos e ordens de serviço**, além de gerar relatórios estáticos para facilitar a consulta e a organização do negócio.


## 🎯 Funcionalidades

- 🔐 Tela de login para administrador
- 👨‍🔧 Cadastro e gerenciamento de **clientes**
- 🚗 Cadastro e gerenciamento de **veículos**
- 🧾 Cadastro e controle de **ordens de serviço**
- 📊 Relatórios internos:
  - Lista de clientes cadastrados
  - Serviços ofertados em um período específico
  - Relatório de preços dos serviços da oficina


## 💾 Armazenamento

Os dados são armazenados em **ArrayLists**, facilitando a manipulação e visualização durante a execução da aplicação. *(Não utiliza banco de dados nesta versão.)*


## 🖼️ Interface Gráfica

A interface foi construída utilizando **Java Swing**, oferecendo uma navegação amigável e funcional para usuários administrativos.


## 🚀 Como Executar o Projeto

1. Faça o download da pasta zipada e extraia no seu computador
2. Importe o projeto para a sua IDE de preferência
3. Execute a classe Main, utilizando como credenciais para login o usuário **admin** e senha **admin**

## 📌 Observações

Projeto acadêmico/demonstrativo sem persistência em banco de dados.
Futuras versões podem incluir integração com banco de dados e melhorias visuais.
